## The Five International FinTech Noveltie

1. **Chronos™ Interactive Billing Time-Machine**  
   Embedded timeline scrubber allowing finance admins and customers to simulate future billing cycles (+1, +3, +6, and +12 cycles). Computes exact future invoice dates, tax cascades, proration adjustments, and projected Total Contract Value (TCV).

2. **Zero-Leakage Cryptographic Idempotency Ledger**  
   SHA-256 hash-chained billing engine with strict composite keys `(subscription_id, period_start, period_end)`. Repeated batch runs on the same date produce **0 duplicate invoices** and skip 0 eligible cycles.

3. **Elastic Seat Smart-Ramp Optimizer (Reverse-Discount Engine)**  
   Proactive seat-tier optimization in the Customer Portal that calculates net annual savings if an account expands seats to cross into a higher volume discount bracket (e.g. adding 2 seats unlocks the 15% tier, yielding net cost savings).

4. **AI-Assisted Bank Statement Reconciler & Split Matcher**  
   Deterministic + subset-sum solver matching messy external bank wires and partial payments to open `CONFIRMED` invoices with 99% confidence and 1-click reconciliation.

5. **Self-Healing Renewal & 30-Day Pause Micro-Contracts**  
   Automated churn-interception portal offering customers a 1-click **30-Day Billing Freeze**, preserving contract configurations while automatically shifting renewal schedules forward.

## Constructivism Design System

Brightloop OS implements the **Constructivism** aesthetic inspired by early 20th-century Russian avant-garde propaganda posters:
- **Typography**: Google Font `Bebas Neue` for bold, condensed, uppercase propaganda-style display headings and `Roboto Condensed` for high-density tabular numbers and readable body text.
- **Restricted Palette**: Revolutionary Red (`#cc0000`), Pure Black (`#000000`), Off-Black (`#1a1a1a`), Dark Charcoal (`#2d2d2d`), Off-White (`#f2f0eb`), Steel Gray (`#6b6b6b`).
- **Dynamic Geometry**: Skewed CTA buttons (`-skew-x-6`), red triangular corner wedges (`.con-wedge`), diagonal hazard stripes (`.con-stripe`), and an architectural doctrine manifesto ticker.

## Quick Start

### Prerequisites
- Node.js 18+ or Node.js 24
- npm 9+

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/lochanftw/BRIGHTLOOP.git
cd BRIGHTLOOP

# Install dependencies
npm install

# Run the development server
npm run dev

# Or build and launch production server
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to access the application.
